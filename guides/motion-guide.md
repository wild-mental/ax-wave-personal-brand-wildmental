# 움직임 넣기 가이드

교재: 2.5절 영상과 연속 이미지 (35~36쪽) · 2.6절 스크롤 진입 전환과 클릭 · 탭 조작 (37~39쪽) · 2.7절 점검과 짝 확인 (39~40쪽) · 부록 A-3 브라우저로 열어 보기와 휴대폰 화면 보기 (51쪽) · 쓰는 날: Day 2 오후 · 쓰는 곳: 작업 폴더의 `index.html` · `images/`, 워크시트 「세 가지 움직임」 · 「동작 점검 기록」

## 이 가이드에서 볼 것

사이트에 반드시 넣을 세 가지 움직임(미디어 재생 · 스크롤 진입 전환 · 클릭 · 탭 조작)을 하나씩 넣고, 휴대폰 화면과 짝 확인으로 점검하는 순서입니다. 움직임마다 왜 넣는지와 백유림의 예는 교재 2.5~2.7절에 있습니다. 이 가이드는 재료 준비, 지시 뒤에 "이렇게 나오면 정상"인 모습, 동작 줄이기 · 키보드 · 휴대폰 확인 방법, 다시 지시하는 말을 채웁니다.

| 순서 | 하는 일 | 지시문 |
|---|---|---|
| 0 | 복사본 남기기 | — |
| 1 | 미디어 재료 준비 (사진 2~3장 또는 짧은 영상) | — |
| 2 | ① 미디어 재생 넣기 | 「미디어 재생 지시문」 |
| 3 | ② 스크롤 진입 전환 넣기 | 「스크롤 진입 지시문」 |
| 4 | ③ 클릭 · 탭 조작 넣기 | 「자세히 열기 지시문」 |
| 5 | 동작 줄이기 · 키보드 확인 | — |
| 6 | 휴대폰 화면 점검, 이미지 없을 때 확인 | — |
| 7 | 짝 확인, 동작 점검 기록 | — |

**한 가지를 넣고 브라우저로 확인한 뒤 다음 것을 넣습니다.** 세 지시문을 한꺼번에 보내지 않습니다(교재 2.6절).

## 0. 복사본 남기기

움직임은 화면 여러 곳을 건드립니다. 시작하기 전에 지금의 사이트를 남깁니다.

```text
지금 index.html 을 index-before-motion.html 로 복사해 둬. 복사본은 고치지 마. 복사가 끝나면 다음 지시를 기다려 줘.
```

되돌리는 법은 「[Claude Code 사이트 제작 가이드](claude-code-site-guide.md)」 6번을 봅니다.

## 1. 미디어 재료 준비

「순서와 시각화 전략표」에서 **[미디어 재생]** 자리를 확인하고, 그 자리에 쓸 재료를 `images/`에 넣습니다. 셋 가운데 하나면 됩니다.

| 재료 | 준비하는 법 | 지킬 것 |
|---|---|---|
| 연속 이미지 (가장 쉬움) | 한 가지 메시지를 이어 보여 줄 사진 2~3장. 본인 사진 · 화면 캡처 · 생성 이미지 모두 됩니다(「[룩앤필과 이미지 가이드](lookfeel-image-guide.md)」) | 사진의 비율과 크기를 맞춥니다. 파일 이름에 순서를 넣습니다. 예) `hero-1.jpg` · `hero-2.jpg` |
| 짧은 영상 | 화면 녹화나 휴대폰 영상을 5~15초로 자릅니다 | `.mp4` 파일, 소리 없이 써도 되는 장면, 10MB 안팎 이하 |
| GIF | 이미 가진 GIF가 있을 때만 | 파일이 크면 연속 이미지로 바꿉니다 |

**화면 녹화하기.** 작업 과정이나 내 프로젝트 화면을 짧게 녹화해 영상으로 씁니다.

| | Mac | Windows |
|---|---|---|
| 화면 녹화 | `Cmd+Shift+5` → 아래 막대에서 **선택 부분 기록** → 영역을 고르고 **기록**. 끝낼 때는 메뉴 막대의 정지 버튼 | **캡처 도구**를 열고 녹화(비디오 카메라 아이콘) → **새로 만들기** → 영역 선택 → **시작**. 끝낼 때는 정지 버튼 |
| 앞뒤 자르기 | 녹화 파일을 QuickTime Player로 열고 **편집 → 다듬기** | 녹화 파일을 **Clipchamp**나 사진 앱의 동영상 편집으로 열고 자르기 |

녹화할 때 알림, 개인 이메일, 다른 사람의 이름이 화면에 나오지 않게 합니다. 영상이 25MB를 넘으면 저장소에 올라가지 않으니 짧게 자릅니다.

## 2. 움직임 ① 미디어 재생

1. 「순서와 시각화 전략표」의 미디어 재생 자리 「미디어 · 연출」 칸에 **[미디어 재생]** 표시가 있는지 봅니다. 지시문이 이 표시로 자리를 찾습니다.
2. 지시문 킷의 「[미디어 재생 지시문](../kits/claude-code-prompts.md)」을 복사해 보냅니다.
3. 브라우저에서 새로 고칩니다.

**이렇게 나오면 정상입니다.**

- 연속 이미지라면 사진이 4초쯤마다 부드럽게 바뀝니다. 영상이라면 소리 없이 반복 재생됩니다.
- 재생 · 정지 버튼이 보이고, 누르면 멈추고 다시 누르면 이어서 움직입니다. 버튼 글자나 모양이 상태에 따라 바뀝니다(예: [일시정지] ↔ [재생]).
- 다른 섹션은 그대로입니다. Claude Code가 확인하는 방법을 한 줄로 알려 줍니다.

움직이는 장면이 전하는 메시지가 하나인지 봅니다(교재 2.5절). 사진 세 장이 서로 다른 이야기를 하면 한 장을 빼거나 바꿉니다.

## 3. 움직임 ② 스크롤 진입 전환

1. **[스크롤 진입 전환]** 자리를 확인하고 지시문 킷의 「[스크롤 진입 지시문](../kits/claude-code-prompts.md)」을 보냅니다.
2. 브라우저를 새로 고치고, 페이지 맨 위에서 천천히 아래로 스크롤합니다.

**이렇게 나오면 정상입니다.**

- 그 섹션이 화면에 들어올 때 카드나 항목이 아래에서 위로 차례로 나타납니다.
- 위로 올라갔다 다시 내려와도 이미 나타난 것은 사라지지 않습니다.
- 페이지를 처음 열었을 때 이미 화면 안에 있던 내용은 바로 보입니다.

**가장 흔한 고장은 "아예 안 보이는 것"입니다.** 스크롤해도 그 섹션이 비어 있으면 아래 표의 다시 지시하는 말을 보냅니다. 이 상태로 공개하면 청자는 근거자료를 볼 수 없습니다.

스크롤 위치에 따라 장면이 계속 바뀌는 효과(스크롤 진행률 연동)는 선택 심화입니다. 세 가지 움직임이 모두 동작한 뒤에 시간이 남을 때만 시도합니다.

## 4. 움직임 ③ 클릭 · 탭 조작

1. **[클릭 · 탭 조작]** 자리를 확인하고 지시문 킷의 「[자세히 열기 지시문](../kits/claude-code-prompts.md)」을 보냅니다.
2. 브라우저를 새로 고칩니다.

**이렇게 나오면 정상입니다.**

- 항목마다 [자세히] 버튼이 있고, 누르면 실제 화면과 긴 설명이 열리며 버튼 글자가 [접기]로 바뀝니다.
- [접기]를 누르면 닫히고 다시 [자세히]가 됩니다.
- 열린 내용에 「미디어 제작 목록」의 화면 캡처가 들어가 있습니다. 없으면 회색 상자 대신 어떤 화면을 넣을지 지시합니다.

## 5. 동작 줄이기와 키보드 확인 (한 줄씩)

이 두 가지는 워크시트에 한 줄씩만 적습니다. 한 번씩 해 보고 결과를 적으면 됩니다.

### 동작 줄이기

'동작 줄이기'는 화면의 움직임을 줄여 달라는 기기 설정입니다(교재 부록 A-3).

| | 켜는 곳 (확인할 때) | 확인한 뒤 |
|---|---|---|
| Mac | **시스템 설정 → 손쉬운 사용 → 디스플레이 → 동작 줄이기** 켜기 | 다시 끕니다 |
| Windows | **설정 → 접근성 → 시각 효과 → 애니메이션 효과** 끄기 | 다시 켭니다 |

설정을 바꾼 뒤 브라우저를 새로 고칩니다. 미디어 재생은 멈춘 상태로 보이고, 스크롤 진입 전환은 처음부터 내용이 보이면 정상입니다. 설정은 꼭 원래대로 돌려놓습니다.

### 키보드

1. 브라우저 주소창을 한 번 누른 뒤 `Tab` 키를 여러 번 누릅니다.
2. 링크와 버튼에 차례로 테두리(초점 표시)가 옮겨 가는지 봅니다.
3. 재생 · 정지 버튼과 [자세히] 버튼에 초점이 왔을 때 `Enter`를 눌러 동작하는지 봅니다.

## 6. 휴대폰 화면 점검 (2.7)

1. Chrome에서 개발자 도구를 엽니다(Mac `Cmd+Option+I`, Windows `F12`).
2. 개발자 도구 왼쪽 위의 휴대폰 모양 아이콘(기기 화면 보기)을 누릅니다. 단축키는 Mac `Cmd+Shift+M`, Windows `Ctrl+Shift+M`입니다.
3. 화면 위쪽의 기기 목록에서 휴대폰 기종(예: iPhone 계열)을 고릅니다.
4. 맨 위부터 맨 아래까지 스크롤하며 읽습니다. 세 가지 움직임도 이 화면에서 한 번씩 해 봅니다. [자세히]는 마우스로 누르면 탭과 같습니다.
5. 다 보면 같은 아이콘을 다시 눌러 기기 화면 보기를 끄고, 개발자 도구를 닫습니다.

볼 것: 글자가 겹치거나 화면 밖으로 넘치지 않는가, 가로로 밀리지 않는가, 사진의 중요한 부분이 잘리지 않는가, 버튼이 손가락으로 누를 만큼 큰가.

### 이미지가 없을 때 확인 (한 줄)

1. Finder(Windows는 파일 탐색기)에서 `images/`의 사진 하나의 이름 끝에 `-x`를 붙여 잠깐 바꿉니다. 예) `profile.jpg` → `profile-x.jpg`
2. 브라우저를 새로 고쳐 그 자리에 설명 글(대체 텍스트)이 남는지, 페이지가 무너지지 않는지 봅니다.
3. **이름을 원래대로 돌려놓습니다.**

## 7. 짝 확인과 동작 점검 기록

짝 확인은 교재 2.7절의 순서대로 합니다. 내 노트북을 짝에게 건네고 아무 설명도 하지 않습니다. 짝이 끝까지 읽은 뒤 세 질문에 답하면, 내가 「동작 점검 기록」에 받아 적습니다. 짝의 말은 고치지 않고 그대로 적습니다. 내 의도와 다르게 읽힌 곳 하나를 「내일 고칠 곳 한 가지」에 적습니다.

하루를 마칠 때 작업 폴더 안의 파일과 폴더를 모두 비공개 저장소에 올립니다(「[작업 폴더와 비공개 저장소 준비 가이드](workspace-repo-setup-guide.md)」 6번).

## 다시 지시하는 말

| 이렇게 나왔다 | 다시 지시하는 말 |
|---|---|
| 연속 이미지가 바뀌지 않는다 | 〈섹션〉의 연속 이미지가 바뀌지 않아. 원인을 찾아 쉬운 말로 설명하고, 그 부분만 고쳐 줘. |
| 사진이 바뀔 때 화면이 덜컹거린다 | 연속 이미지의 사진들이 같은 크기로 보이게 맞춰 줘. 바뀔 때 아래 내용이 움직이지 않게 해 줘. |
| 정지 버튼을 눌러도 계속 움직인다 | 재생 · 정지 버튼을 누르면 실제로 멈추고, 다시 누르면 이어서 움직이게 고쳐 줘. 버튼 글자도 상태에 맞게 바꿔 줘. |
| 영상이 재생되지 않는다 | images 폴더의 〈영상 파일 이름〉이 재생되지 않아. 소리 없이 자동 재생되도록 설정을 확인하고, 파일 이름이 맞는지 봐 줘. |
| 스크롤해도 내용이 안 나타난다 | 스크롤해도 〈섹션〉의 카드가 계속 안 보여. 화면에 들어오면 반드시 보이게 고쳐 주고, 문제가 생기면 처음부터 보이게 해 줘. |
| 동작 줄이기를 켜도 움직인다 | 기기의 동작 줄이기를 켰는데도 〈움직임〉이 계속 움직여. 동작 줄이기를 켠 사람에게는 멈추거나 처음부터 보이게 고쳐 줘. |
| [자세히]가 열리기만 하고 닫히지 않는다 | [자세히]를 다시 누르면 닫히고 글자가 [자세히]로 돌아오게 해 줘. 다른 곳은 고치지 마. |
| Tab으로 버튼에 닿지 않는다 | 재생 · 정지 버튼과 [자세히] 버튼이 키보드 Tab으로 닿고 Enter로 눌리게 해 줘. 초점이 왔을 때 테두리가 보이게 해 줘. |
| 휴대폰에서 가로로 밀린다 | 휴대폰 화면(가로 390px)에서 페이지가 가로로 밀려. 화면 밖으로 넘치는 요소를 찾아 그것만 고쳐 줘. |

## 자주 하는 실수와 고친 예

- **세 지시문을 한 번에 보냈다** — 세 움직임이 한꺼번에 들어가 어느 것이 화면을 깨뜨렸는지 알 수 없었습니다. → `index-before-motion.html`로 되돌리고, 하나씩 넣으며 그때마다 새로 고쳐 봅니다.
- **모든 섹션을 움직이게 했다** — 화면 전체가 들썩여 정작 근거자료가 눈에 들어오지 않았습니다. → 전략표에 정한 자리에만 남기고 나머지 움직임은 빼 달라고 합니다.
- **연속 이미지 세 장이 서로 다른 이야기를 했다** — 동아리 사진 · 여행 사진 · 작업 화면이 번갈아 나왔습니다. → 대표 슬로건을 보여 주는 한 가지 메시지로 사진을 다시 고릅니다.
- **동작 줄이기 설정을 확인하고 그대로 두었다** — 다른 사이트와 앱의 움직임까지 줄어 있었습니다. → 5번의 「확인한 뒤」대로 원래대로 돌립니다.
- **이미지 없을 때 확인 뒤 파일 이름을 되돌리지 않았다** — 공개한 사이트에서 프로필 사진이 빠졌습니다. → `-x`를 지워 원래 이름으로 돌리고 새로 고쳐 사진이 보이는지 봅니다.

## 완료 기준 체크리스트 확인 방법

- **세 가지 움직임:** 2~4번의 "이렇게 나오면 정상" 모습이 모두 보이는지, 5번의 동작 줄이기 · 키보드를 한 번씩 해 봤는지 확인하고 `- [ ]`를 `- [x]`로 바꿉니다.
- **동작 점검 기록:** 「결과」 칸에 "됨" · "안 됨 → 고침" · "안 됨(내일 고칠 곳)"처럼 확인한 결과를 적었는지, 짝의 세 답과 내일 고칠 곳 한 가지가 있는지, 오늘 만든 파일을 저장소에 올렸는지 봅니다.

## 막혔을 때

- **고쳤다는데 움직임이 그대로입니다.** 강력 새로 고침(Mac `Cmd+Shift+R`, Windows `Ctrl+Shift+R`)을 하고, 주소창 끝이 `index.html`인지 봅니다.
- **개발자 도구가 열리지 않거나 휴대폰 아이콘이 안 보입니다.** Chrome 오른쪽 위 **⋮ → 도구 더보기 → 개발자 도구**로 엽니다. 개발자 도구 창이 좁으면 아이콘이 숨으니 창을 넓힙니다.
- **화면 녹화가 안 됩니다(Mac).** 처음 녹화할 때 화면 기록 권한을 묻습니다. **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록**에서 허용합니다.
- **영상 파일이 너무 큽니다.** 더 짧게 자르거나, 영상 대신 장면 2~3개를 캡처해 연속 이미지로 씁니다(교재 2.5절).
- **움직임을 넣다 사이트가 망가졌습니다.** 고치려고 여러 번 지시하기보다 `index-before-motion.html`로 되돌리고 한 가지씩 다시 넣는 편이 빠릅니다.
