# 공개와 배포 가이드

교재: 3.2절 CTA 다듬기 (42~44쪽) · 3.3절 공개 전 확인과 배포 (44~45쪽) · 부록 A-4 공개 주소 확인 (51쪽) · 쓰는 날: Day 3 오전 · 쓰는 곳: 워크시트 「CTA 문구」 · 「공개 확인 기록」, 작업 폴더의 `index.html` · `public/`, Claude Code와 Vercel

## 이 가이드에서 볼 것

사이트의 마지막 장면인 CTA(Call To Action, 행동 유도: 페이지를 본 사람에게 다음 행동을 제안하는 문구와 버튼)를 다듬고, 공개해도 되는 것만 남았는지 확인한 뒤, Claude Code에 Vercel 배포를 맡겨 공개 주소를 받고, 로그인하지 않은 브라우저와 휴대폰으로 여는 순서입니다. CTA의 세 부분(선언 · 고를 수 있는 분야 · 하나의 창구)과 공개 전 세 가지 확인은 교재 3.2 · 3.3절에 있습니다. 이 가이드는 창구 고르기, 공개 전 확인을 손으로 하는 방법, 배포 중 허락 요청, "이렇게 나오면 정상"인 공개 주소, 다시 지시하는 말을 채웁니다.

| 순서 | 하는 일 | 지시문 |
|---|---|---|
| 1 | CTA 문구 쓰기, 창구 고르기 | — (내가 함) |
| 2 | 사이트의 마지막 섹션 고치기 | 「CTA 지시문」 |
| 3 | 공개 전 세 가지 확인 | — (내가 함) |
| 4 | 공개 폴더 만들고 Vercel에 배포 | 「Vercel 배포 지시문」 |
| 5 | 시크릿 창 · 내 휴대폰 · 짝의 휴대폰으로 열기 | — |
| 6 | 고친 뒤 다시 배포 | 「Vercel 배포 지시문」 2~5번 |

배포에는 사전 안내 3 · 4번(Node.js 설치, Vercel 계정과 로그인)이 끝나 있어야 합니다. 아직이면 [사전 안내](../pre-course-notice.md)부터 합니다.

## 1. CTA 문구 쓰기와 창구 고르기

「CTA 문구」 표의 세 칸을 씁니다. 「계층별 슬로건 표」의 지향점 슬로건과 텍스트 이력서 3번 「지향점」이 출발점입니다.

- **선언:** 지향점 슬로건을 그대로 쓰거나 한 문장으로 다듬습니다.
- **고를 수 있는 분야:** 청자가 "내 일과 맞나?"를 바로 맞춰 볼 수 있는 이름으로 두세 가지에서 네 가지. 예) "동네 가게 온라인 홍보 협업 / 대학생 대상 디자인 특강 / 사이드 프로젝트 팀원"
- **하나의 창구:** 사이트에 공개해도 되는 연락 방법 하나.

| 창구 | 좋은 점 | 확인할 것 |
|---|---|---|
| 업무용 이메일 | 누르면 메일이 열리고, 고른 분야를 메일 제목에 담을 수 있습니다 | 개인 이메일이 아닌, 공개해도 되는 주소인가. 스팸 메일이 늘 수 있습니다 |
| LinkedIn 프로필 | 이메일을 공개하지 않아도 됩니다 | 프로필이 공개로 열리는가. 고른 분야는 담기지 않으니 버튼 위에 "메시지에 분야를 적어 주세요" 한 줄을 둡니다 |
| 신청 폼 (예: Google Forms) | 고른 분야 · 연락처를 항목으로 받을 수 있습니다 | 폼이 로그인 없이 열리는가. 응답을 누가 보는지 |

개인 휴대폰 번호, 집 주소, 메신저 개인 아이디는 창구로 쓰지 않습니다.

## 2. 사이트의 마지막 섹션 고치기

1. 「CTA 문구」를 저장하고, 지시문 킷의 「[CTA 지시문](../kits/claude-code-prompts.md)」을 보냅니다.
2. 브라우저를 새로 고치고 맨 아래까지 내려갑니다.

**이렇게 나오면 정상입니다.**

- 선언 문장이 크게 보이고, 그 아래에 분야 버튼이 있습니다. 버튼을 누르면 고른 표시가 나고, 다시 누르면 풀립니다. 여러 개 고를 수 있습니다.
- 창구 버튼은 하나입니다.
- 이메일 창구라면, 분야를 고르고 창구 버튼을 누를 때 메일 앱의 새 메일이 열리고 제목에 고른 분야가 들어 있습니다.
- 「CTA 문구」에 적지 않은 연락처는 어디에도 없습니다.

메일 앱을 한 번도 설정하지 않은 컴퓨터에서는 창구 버튼을 눌러도 아무 일이 없거나 메일 앱 설정 화면이 열립니다. 고장이 아닙니다. 휴대폰에서 확인하거나(5번), 브라우저 아래 상태 표시줄에 `mailto:`로 시작하는 주소가 보이는지로 확인합니다.

## 3. 공개 전 세 가지 확인

공개 주소는 누구나 열 수 있고, 한 번 퍼진 링크는 거둬들이기 어렵습니다(교재 3.3절). 배포 지시문을 보내기 전에 세 가지를 직접 확인합니다.

### 공개해도 되는 정보만 있는가

텍스트 이력서 10번 「공개 범위 메모」를 열어 두고 이렇게 묻습니다.

```text
@index.html 에서 전화번호 · 이메일 · 주소 · 사람 이름 · 회사 이름처럼 보이는 글을 모두 찾아 목록으로 보여 줘. 줄마다 @resume.md 의 「공개 범위 메모」에서 공개인지 비공개인지도 함께 적어 줘. 파일은 고치지 마.
```

비공개인 것이 있으면 한 가지씩 지우게 합니다. 사진 속 다른 사람의 얼굴, 화면 캡처 속 이메일 · 알림은 브라우저로 사진을 하나씩 크게 보며 직접 확인합니다.

### 표기가 붙어 있는가

- 생성 이미지 옆이나 페이지 아래에 '생성 이미지' 표기가 있는가
- 지어낸 예시 · 가상 자료가 있다면 그 표기가 있는가

### 공유될 때의 모습

페이지 제목, 한 줄 설명, 공유 이미지는 「Vercel 배포 지시문」 1번이 넣습니다(교재 3.3절의 기본 SEO). 제목은 "이름 · 하는 일", 설명은 대표 슬로건, 공유 이미지는 프로필 사진입니다. 공유 이미지로 쓸 사진이 `images/`에 있는지만 미리 봅니다.

## 4. 공개 폴더 만들고 Vercel에 배포

1. 지시문 킷의 「[Vercel 배포 지시문](../kits/claude-code-prompts.md)」을 복사합니다.
2. (선택) 공개 주소에 내 이름이 들어가게 하려면 지시문 끝에 한 줄을 더합니다. 처음 배포할 때만 정할 수 있습니다.

   ```text
   Vercel 프로젝트 이름은 〈영문 이름〉-site 로 해 줘. 이미 쓰는 이름이면 알려 줘.
   ```

3. 보냅니다. Claude Code가 차례로 일을 하며 허락을 묻습니다.

| 묻는 것 | 이렇게 합니다 |
|---|---|
| `index.html` 고치기 (제목 · 설명 · 공유 이미지) | 허락합니다 |
| `public` 폴더 만들기, `index.html` · `images` 복사 | 경로가 `personal-brand-site` 안이면 허락합니다 |
| `vercel`로 시작하는 명령 실행 (배포) | 허락합니다. 이 수업에서 Claude Code에 명령 실행을 허락하는 것은 배포 때뿐입니다 |
| `resume.md` · `worksheet.md` · `DESIGN.md`를 `public`에 복사 | 거절합니다 |
| 프로그램 설치, 작업 폴더 밖 수정, 관리자 권한(비밀번호 입력) 요구 | 거절하고 "설치하지 말고, 왜 필요한지 먼저 설명해 줘."라고 보냅니다. Vercel CLI 설치는 사전 안내에서 끝냈습니다 |

**이렇게 나오면 정상입니다.**

- `public` 폴더 안의 파일 목록이 나오고, `index.html`과 `images` 폴더뿐입니다. 이력서 · 워크시트가 없다고 확인해 줍니다.
- 배포가 끝나면 `https://`로 시작하고 `.vercel.app`으로 끝나는 공개 주소를 알려 줍니다.
- 작업 폴더의 `public` 안에 `.vercel`이라는 숨은 폴더가 생길 수 있습니다. Vercel이 이 폴더가 어느 프로젝트인지 기억하는 파일이라 그대로 둡니다. Finder · 파일 탐색기에서는 보통 보이지 않습니다.

**주소가 두 개 나오면** 프로젝트 이름으로 된 짧은 주소(예: `〈프로젝트 이름〉.vercel.app`)가 공개 주소입니다. 배포할 때마다 바뀌는 긴 주소는 시크릿 창에서 Vercel 로그인 화면이 나올 수 있습니다. 어느 것인지 모르겠으면 이렇게 묻습니다.

```text
방금 배포한 사이트의 프로덕션 주소(프로젝트 이름으로 된 짧은 주소)를 알려 줘. 그 주소가 로그인 없이 누구에게나 열리는지도 확인해 줘.
```

## 5. 시크릿 창 · 내 휴대폰 · 짝의 휴대폰으로 열기 (부록 A-4)

1. **시크릿 창:** Chrome에서 새 시크릿 창(Mac `Cmd+Shift+N`, Windows `Ctrl+Shift+N`)을 열고 공개 주소를 붙여 넣습니다. 첫 화면부터 마지막 CTA까지 내려가 봅니다.
2. **내 휴대폰:** 공개 주소를 메신저의 나에게 보내기 등으로 휴대폰에 보내고 엽니다. 세 가지 움직임을 한 번씩 해 봅니다.
3. **짝의 휴대폰:** 짝에게 주소를 보냅니다. 메신저 미리보기에 제목 · 설명 · 공유 이미지가 보이는지 함께 봅니다.
4. 결과를 「공개 확인 기록」에 적습니다. 공개 주소 칸에는 짧은 주소를 적습니다.

미리보기는 메신저가 한 번 읽어 간 뒤 한동안 바뀌지 않을 수 있습니다. 공유 이미지를 고친 뒤에도 옛 미리보기가 보이면 다른 메신저 대화방이나 짝의 휴대폰에서 처음 보내 확인합니다.

## 6. 고친 뒤 다시 배포하기

공개한 뒤 사이트를 고치면 **작업 폴더의 `index.html`만 바뀌고 `public` 안의 사본은 그대로**입니다. 다시 배포할 때는 `public`을 새로 채운 뒤 배포합니다.

```text
public 폴더 안의 index.html 과 images 폴더를 작업 폴더의 최신 index.html 과 images 폴더로 바꿔 줘. resume.md · worksheet.md · DESIGN.md 는 넣지 마. public 폴더 안의 파일 목록을 보여 준 뒤, 같은 Vercel 프로젝트에 프로덕션으로 다시 배포하고 공개 주소를 알려 줘.
```

같은 프로젝트로 다시 배포하면 공개 주소는 그대로이고 내용만 바뀝니다. 시크릿 창에서 강력 새로 고침(Mac `Cmd+Shift+R`, Windows `Ctrl+Shift+R`)으로 바뀐 것을 확인합니다.

## 다시 지시하는 말

| 이렇게 나왔다 | 다시 지시하는 말 |
|---|---|
| 분야 버튼이 하나만 골라진다 | 협력 분야 버튼을 여러 개 고를 수 있게 하고, 고른 것을 다시 누르면 풀리게 해 줘. 다른 곳은 고치지 마. |
| 고른 분야가 메일 제목에 안 담긴다 | 창구 버튼을 누를 때 고른 분야 이름이 메일 제목에 함께 들어가게 해 줘. 아무것도 고르지 않았으면 "함께 할 일 제안"으로. |
| 내가 적지 않은 연락처가 생겼다 | 「CTA 문구」에 없는 연락처를 모두 지워 줘. 창구는 〈내 창구〉 하나만 남겨 줘. |
| `public`에 이력서 · 워크시트가 들어갔다 | public 폴더에서 resume.md · worksheet.md · DESIGN.md 와 index.html · images 가 아닌 파일을 모두 지우고, 파일 목록을 다시 보여 줘. 배포는 아직 하지 마. |
| Vercel 로그인이 안 되어 있다고 한다 | Vercel 로그인을 진행해 줘. 브라우저에서 내가 승인해야 하면 열 주소와 할 일을 알려 주고 기다려 줘. |
| `vercel` 명령을 찾을 수 없다고 한다 | Vercel CLI 가 설치되어 있는지 확인해 줘. 없으면 관리자 권한 없이 쓸 수 있는 방법(npx)으로 배포해 줘. |
| 시크릿 창에서 Vercel 로그인 화면이 나온다 | 시크릿 창에서 열면 Vercel 로그인 화면이 나와. 로그인 없이 열리는 프로덕션 주소를 알려 주고, 공개 설정을 확인해 줘. |
| 미리보기에 공유 이미지가 안 나온다 | 공유 이미지 설정의 이미지 주소를 공개 주소로 시작하는 전체 주소로 바꿔 줘. 그다음 public 을 새로 채워 다시 배포해 줘. |
| 배포가 실패했다는데 이유를 모르겠다 | 배포가 왜 실패했는지 쉬운 말로 설명하고, 내가 할 일과 네가 할 일을 나눠서 알려 줘. |

## 자주 하는 실수와 고친 예

- **CTA를 "연락 주세요"로만 썼다** — 청자가 무엇을 제안해야 할지 몰랐습니다. → 선언(지향점 슬로건)과 고를 수 있는 분야를 먼저 쓰고, 창구는 그 아래에 하나만 둡니다.
- **창구를 셋 넣었다** — 이메일 · LinkedIn · 오픈채팅을 모두 넣어 어느 것을 눌러야 할지 망설이게 했습니다. → 청자가 가장 많이 쓸 하나만 남깁니다.
- **작업 폴더 전체를 배포했다** — 이력서와 워크시트까지 공개 주소에서 열렸습니다. → 바로 `public`만 남기고 다시 배포한 뒤, 시크릿 창에서 `공개 주소/resume.md`를 열어 보이지 않는지 확인합니다. 이미 퍼졌을 수 있는 개인 정보가 있었다면 강사에게 알립니다.
- **고친 뒤 `public`을 새로 채우지 않고 배포했다** — 공개 주소에는 옛 사이트가 그대로였습니다. → 6번의 말로 `public`을 새로 채운 뒤 배포합니다.
- **긴 주소를 워크시트에 적었다** — 나중에 열어 보니 Vercel 로그인 화면이 나왔습니다. → 4번의 말로 짧은 프로덕션 주소를 받아 고쳐 적습니다.

## 완료 기준 체크리스트 확인 방법

- **CTA 문구:** 선언이 「계층별 슬로건 표」의 지향점 슬로건과 같은 뜻인지, 분야가 두 개 이상인지, 창구가 하나이고 1번 표의 공개용 연락 방법인지 봅니다.
- **공개 확인 기록:** 시크릿 창에서 로그인 화면 없이 열렸는지, 휴대폰에서 세 가지 움직임을 해 봤는지, 시크릿 창에서 `공개 주소/resume.md`와 `공개 주소/worksheet.md`를 열었을 때 '찾을 수 없음'(404)이 나오는지 봅니다.
