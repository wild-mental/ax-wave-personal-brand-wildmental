### 계층별 슬로건 표 (1.5절)

| 계층 | 답하는 질문 | 내 슬로건 |
|---|---|---|
| 성격 | 나는 어떤 사람인가? | |
| 능력 | 나는 무엇을 잘하는가? | |
| 이력 | 나는 무엇을 해 왔는가? 여러 일을 하나로 묶으면? | |
| 지향점 | 앞으로 무엇을 하고, 그 의미를 누구와 나누며, 어떻게 함께하고 싶은가? | |
| **대표 슬로건** | 무엇을 위해 일하는 사람인가?(한 줄) | |

대표 슬로건을 고른 이유(한 줄):

**완료 기준 체크리스트**
- [ ] 네 계층에 슬로건이 하나씩 있다
- [ ] 이력 슬로건이 여러 일을 하나로 묶는다
- [ ] 지향점 슬로건에 함께하자는 제안이 들어 있다
- [ ] 대표 슬로건을 골랐고 이유를 적었다
- [ ] 짧다 · 내 말이다 · 근거로 받칠 수 있다 · 다음이 궁금하다 — 네 기준을 통과한다
