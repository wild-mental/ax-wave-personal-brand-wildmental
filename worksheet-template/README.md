# 워크시트 원본과 텍스트 이력서 양식

「개인 브랜드 웹서비스 기획·구현」 교재의 학생용 문서 원본입니다. 이 폴더의 파일을 직접 고치지 말고, 내 컴퓨터의 작업 폴더와 내 비공개 저장소로 옮겨 씁니다. 명령어는 쓰지 않고 GitHub 웹 화면에서만 작업합니다.

| 파일 | 무엇 | 언제 |
|---|---|---|
| [`text-resume-template.md`](text-resume-template.md) | 텍스트 이력서 양식. 열 칸을 채워 작업 폴더에 `resume.md`로 저장합니다 | 수업 전 (사전 과제) |
| [`baek-yurim-resume.md`](baek-yurim-resume.md) | 중심 예제 백유림이 같은 양식을 채운 작성 예. 백유림은 수업을 위해 만든 **가상 인물**이고 경력 · 수치는 지어낸 것입니다 | 수업 전 (참고) |
| [`worksheet.md`](worksheet.md) | 사흘 동안의 산출물을 칸마다 채우고 완료 기준 체크리스트로 확인하는 워크시트 문서 | Day 1~3 |

## 수업 전: 텍스트 이력서

1. 내 컴퓨터의 바탕화면이나 문서 폴더에 `personal-brand-site` 폴더를 만듭니다.
2. [`text-resume-template.md`](text-resume-template.md)를 열고 파일 위쪽 막대의 **Download raw file**(내려받기 아이콘)을 누릅니다.
3. 내려받은 파일을 `personal-brand-site` 폴더로 옮기고 이름을 `resume.md`로 바꾼 뒤 채웁니다.

칸마다 쓰는 요령은 온라인 가이드 「텍스트 이력서 작성 가이드」를 봅니다.

## 첫날: 워크시트

1. 오른쪽 위 **+ → New repository**에서 저장소 이름을 `personal-brand-site`로 쓰고, 공개 범위는 반드시 **Private**(비공개)를 고른 뒤 만듭니다.
2. 이 폴더의 [`worksheet.md`](worksheet.md)를 열고 **Copy raw file**(복사 아이콘)로 내용 전체를 복사합니다.
3. 내 저장소에서 **Add file → Create new file**(빈 저장소라면 **creating a new file**)을 누르고, 파일 이름 `worksheet.md`로 붙여 넣은 뒤 **Commit changes**를 누릅니다.
4. 내 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다.
5. 내 저장소의 `worksheet.md` 화면에서 **Download raw file**(내려받기 아이콘)로 작업 폴더 `personal-brand-site`에 저장합니다. 사흘 동안 채우는 것은 이 작업 폴더의 `worksheet.md`입니다.

클릭 순서는 교재 1.1절 · 부록 A-1과 온라인 가이드 「작업 폴더와 비공개 저장소 준비 가이드」를 봅니다.

## 내 작업 폴더에 생기는 파일

| 파일 · 폴더 | 쓰임 |
|---|---|
| `resume.md` | 텍스트 이력서 (사전 과제) |
| `worksheet.md` | 사흘 동안 채우는 워크시트. 맨 위의 사용법부터 읽습니다 |
| `DESIGN.md` | 앞 과목에서 만든 나만의 DESIGN.md의 사본 (1.9), 룩앤필 규칙 덧붙임 (2.3) |
| `index.html` | 내 사이트 (1.9부터) |
| `images/` | 사진 · 화면 캡처 · 생성 이미지 · 영상 (2.4 · 2.5) |
| `public/` | 공개할 파일만 모은 폴더 (3.3) |

하루를 마칠 때마다 작업 폴더 안의 파일과 폴더를 모두 **Add file → Upload files**로 내 비공개 저장소에 올립니다(교재 부록 A-1).

## 꼭 지킬 것

- 내 저장소는 끝까지 **Private**으로 두고, 강사 `wild-mental`만 초대합니다. 이력서와 워크시트가 들어 있습니다.
- 공개 주소에는 `public/`의 사이트 파일만 올립니다. 이력서와 워크시트는 공개하지 않습니다(교재 3.3절).
- 다른 사람의 얼굴 · 이름 · 말은 공개 허락을 받은 것만 사이트에 씁니다. 생성 이미지에는 '생성 이미지'라고 표기합니다.
