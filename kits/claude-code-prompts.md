```

3. 이 폴더 밖의 파일은 만들거나 고치지 마.
```

## 2. 자기 이해 질문 지시문 (1.3절)

```
@resume.md 를 읽어 줘. 나는 개인 브랜드 사이트를 만들려고 내 장점 · 반복되는 관심 · 앞으로의 목표를 찾는 중이야.
1. 이력서를 바탕으로 질문을 한 번에 하나씩 해 줘. 질문은 여섯 개까지만.
   (예: 사람들이 나에게 자주 부탁하는 일, 시간 가는 줄 모르고 하는 일, 칭찬받았던 일, 끝까지 해낸 일, 3년 뒤 하고 싶은 일, 나를 설명하는 말 세 개)
2. 내가 여섯 개에 다 답하면, 내 답만으로 아래 표를 채운 초안을 보여 줘.
   | 장점 1 — 일화 | 장점 2 — 일화 | 장점 3 — 일화 | 반복되는 관심 | 앞으로의 목표 | 성향을 설명하는 말 세 개 |
3. 이력서와 내 답에 없는 경력 · 성과 · 일화는 지어내지 마. 비어 있으면 "답 없음"이라고 써 줘.
4. worksheet.md 는 고치지 말고 대화창에만 보여 줘.
```

확인할 것: 초안의 모든 줄이 내 답에서 나왔는가? 다듬어서 「자기 이해 노트」에 내가 옮겨 씁니다.

## 3. 상품으로서의 나 점검 지시문 (1.4절)

```
@worksheet.md 의 「상품으로서의 나」와 @resume.md 를 읽어 줘.
1. 누구에게 · 어떤 가치 · 다른 점 · 믿을 근거 네 칸이 서로 맞는지 봐 줘.
2. '어떤 가치'가 내가 하는 일이 아니라 상대가 얻는 결과로 쓰였는지 봐 줘.
3. '믿을 근거'에 이력서에서 더 넣을 만한 것이 있으면 이력서의 어느 줄인지 함께 알려 줘.
4. 고쳐 쓰지 말고, 질문과 제안만 세 개 이내로 해 줘.
```

## 4. 슬로건 후보 지시문 (1.5절)

```
@worksheet.md 의 「자기 이해 노트」와 「상품으로서의 나」를 읽어 줘. 개인 브랜드 사이트에 넣을 슬로건 후보가 필요해.
1. 성격 · 능력 · 이력 · 지향점 계층마다 슬로건 후보를 세 개씩 써 줘. 한 후보는 두 문장 안으로.
   - 성격: 나는 어떤 사람인가
   - 능력: 나는 무엇을 잘하는가
   - 이력: 내가 해 온 여러 일을 하나로 묶으면 무엇을 위한 것이었나
   - 지향점: 앞으로의 활동 선언 + 청자와 나누고 싶은 의미 + 함께하자는 제안
2. 대표 슬로건 후보도 한 줄로 세 개 써 줘. 무엇을 위해 일하는 사람인지 단번에 알 수 있게.
3. 후보마다 노트의 어느 줄에서 나왔는지 괄호로 표시해 줘.
4. 노트에 없는 경력이나 성과는 넣지 마. 누구 이름을 넣어도 통하는 흔한 문장은 피해 줘.
5. worksheet.md 는 고치지 말고 대화창에만 보여 줘.
```

확인할 것: 짧다 · 내 말이다 · 근거로 받칠 수 있다 · 다음이 궁금하다 — 네 기준으로 내가 고릅니다.

```
3. 근거를 찾지 못한 슬로건은 "근거 없음"이라고 표시해 줘.
4. 이력서에 없는 숫자나 성과는 만들지 마. 숫자에는 이력서에 적힌 기간 · 대상을 함께 적어 줘.
5. worksheet.md 는 고치지 말고 대화창에만 보여 줘.
```

## 15. Vercel 배포 지시문 (3.3절)

```
내 개인 브랜드 사이트를 공개하려고 해.
```
