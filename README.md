# 개인 브랜드 웹서비스 기획·구현 · 온라인 자료실

교재 「개인 브랜드 웹서비스 기획·구현」(2026년 12월 9일~11일)과 함께 쓰는 온라인 자료실입니다. 이 첫 화면이 **교재와 자료실을 잇는 표**입니다.

- 교재에서 `→ 온라인 가이드: 「이름」` 표시를 봤다면, 아래 표에서 같은 **절**을 찾으세요. 가이드 이름은 교재와 글자 하나까지 같습니다. 교재 부록 A 첫 쪽의 「온라인 가이드 목록」과 같은 짝입니다.
- 「교재 쪽」은 그 절이 시작하는 쪽입니다.
- 「함께 쓰는 자료」 열은 그 절에서 같이 여는 것입니다.
  - **워크시트:** 내 작업 폴더의 `worksheet.md`에서 그 이름의 칸을 엽니다.
  - **킷:** 지시문 킷에서 그 이름의 지시문을 복사합니다.
- 도구 화면은 자주 바뀝니다. 교재의 부록 A로 흐름을 잡고, 실제 버튼 위치는 여기서 확인하세요.
- 실습 중에 막히면 [막혔을 때 모음](help/stuck-guide.md)부터 보세요.

## 처음 오셨다면

1. 이 자료실 주소 `https://wild-mental.github.io/ax-wave-personal-brand-wildmental/`를 즐겨찾기에 넣습니다.
2. 수업 전에 [사전 안내](pre-course-notice.md)를 따라 준비합니다. 사전 과제로 내 컴퓨터에 작업 폴더 `personal-brand-site/`를 만들고, 텍스트 이력서를 `resume.md`로 저장해 옵니다.
3. 첫날 GitHub에서 **비공개(Private)** 저장소 `personal-brand-site`를 새로 만듭니다.
4. 자료실 원본(이 자료실의 GitHub 화면)에서 워크시트 원본 [worksheet.md][ws]를 열고 **Copy raw file**로 전체를 복사해, 내 저장소에 같은 이름 `worksheet.md`로 붙여 넣습니다.
5. 내 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다.
6. 내 저장소의 `worksheet.md`를 **Download raw file**로 작업 폴더 `personal-brand-site/`에 내려받고, Claude Code 데스크톱 앱에서 그 폴더를 엽니다. 사흘 동안 채우는 것은 이 작업 폴더의 `worksheet.md`이고, 저장소는 하루를 마칠 때 작업 폴더의 파일을 올리는 보관 공간입니다.

단계별 순서와 막혔을 때 할 일은 「[작업 폴더와 비공개 저장소 준비 가이드](guides/workspace-repo-setup-guide.md)」에 있습니다(교재 1.1절 · 부록 A-1).

## 지켜 주세요

- 비공개 저장소 `personal-brand-site`는 끝까지 **Private**으로 두고 강사 GitHub 아이디 `wild-mental`만 초대합니다. 이력서와 워크시트가 들어 있습니다.
- 공개 주소에는 공개용 폴더 `public/`의 사이트 파일(`index.html` · `images/`)만 올립니다. 이력서 · 워크시트 · `DESIGN.md`는 넣지 않습니다(교재 3.3절).
- 사이트에는 텍스트 이력서 10번 「공개 범위 메모」에서 공개로 정한 것만 둡니다. 다른 사람의 얼굴 · 이름 · 말은 공개 허락을 받은 것만 씁니다.
- 이미지 생성 AI로 만든 이미지에는 '생성 이미지'라고 표기합니다. 실존 인물과 닮은 얼굴, 다른 회사의 로고, 실제로 없었던 일을 사실처럼 보이게 하는 장면은 만들지 않습니다(교재 부록 A-5).
- 중심 예제 백유림의 이력서와 사이트는 따라 할 본보기이지 정답이 아닙니다. 실습은 가급적 내 이름과 내 이력으로 합니다.
