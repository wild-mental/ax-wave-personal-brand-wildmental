# 다른 AI 코딩 도구로 할 때 (OpenAI Codex · Cursor)

쓰는 때: Claude Code를 쓸 수 없거나 사용 한도를 다 써서 한동안 쓸 수 없을 때

## 이 페이지에서 볼 것

Claude 계정에는 일정 시간 동안 쓸 수 있는 양(사용 한도)이 있습니다. 실습 중에 한도를 다 써서 Claude Code를 한동안 쓸 수 없으면, 다른 회사의 AI 코딩 도구로 같은 작업 폴더를 열고 이어서 작업해도 됩니다. 이 페이지는 Claude Code에서 하던 조작이 OpenAI Codex와 Cursor에서는 무엇인지 한 표로 보여 줍니다. 두 도구의 계정과 요금은 각 회사 안내를 따르고, 설치는 각 회사 누리집의 내려받기 안내를 봅니다.

| 그대로인 것 | 도구에 맞출 것 |
|---|---|
| 작업 폴더 `personal-brand-site/`와 그 안의 파일 이름(`resume.md` · `worksheet.md` · `DESIGN.md` · `index.html` · `images/` · `public/`) | 폴더를 여는 메뉴 |
| [지시문 킷](../kits/claude-code-prompts.md)의 지시문 내용. 고치지 않고 그대로 씁니다 | 파일을 가리키는 방법(`@` 표기) |
| 한 번에 한 가지씩 고치고 브라우저로 확인하는 순서, 큰 변경 전 복사본 | 허락을 묻는 방식과 버튼 이름 |
| 워크시트 `worksheet.md`의 칸과 완료 기준 체크리스트 | 명령 실행(배포)을 허락하는 방법 |

## 어느 화면을 쓰나

- **OpenAI Codex**: **ChatGPT 데스크톱 앱**(macOS · Windows) 안에서 씁니다. chatgpt.com/download에서 앱을 받아 로그인하고, 새 대화에서 **Codex**를 고릅니다. 터미널판(CLI)도 있지만 이 수업에서는 터미널이 필요 없는 데스크톱 앱을 씁니다.
- **Cursor**: Cursor 자체가 데스크톱 앱(macOS · Windows)입니다. cursor.com에서 받아 설치하고 로그인합니다. 대화로 일을 시키는 곳은 **Agent**(에이전트: 파일을 읽고 고치는 AI 작업 창)입니다.

## 조작 대응표

| 하는 일 | Claude Code (Code 탭) | OpenAI Codex (ChatGPT 데스크톱 앱) | Cursor |
|---|---|---|---|
| 작업 폴더 열기 | 입력창 아래 **환경 선택**에서 이 컴퓨터, **폴더 선택**에서 `personal-brand-site` | Codex를 고른 뒤 폴더 열기(또는 프로젝트를 만들고 폴더 추가)로 `personal-brand-site`를 고릅니다 | 앱을 열고 폴더를 고릅니다. 편집기 화면에서는 **File → Open Folder**. 그다음 `Cmd+I`(Windows `Ctrl+I`)로 Agent를 엽니다 |
| 파일을 가리키기 (`@`) | `@worksheet.md`처럼 `@`를 치고 후보에서 고릅니다 | 입력창에 `@`를 쳐서 파일 후보가 뜨면 고릅니다. 안 뜨면 "작업 폴더의 worksheet.md 파일"처럼 글로 씁니다 | `@`를 치면 파일 · 폴더 후보가 뜹니다. Claude Code와 같게 씁니다 |
| 파일 고치기 전 허락 | 모드 선택에서 고치기 전에 묻는 모드를 씁니다 | 입력창 아래 권한 선택에서 **Ask for approval**을 고릅니다. **Full access**는 고르지 않습니다 | 파일 편집은 바로 적용되고 바뀐 부분 보기로 확인합니다. 먼저 계획만 받으려면 입력창에서 `Shift+Tab`으로 **Plan Mode**를 켭니다. 명령 실행 허락에서 **Run Everything**은 고르지 않습니다 |
| 브라우저로 확인 | Finder · 파일 탐색기에서 `index.html`을 Chrome으로 열고, 고칠 때마다 새로 고침(Mac `Cmd+R` · Windows `Ctrl+R`) | 같습니다 | 같습니다 |
| 되돌리기 | 큰 변경 전 복사본 `index-before-<다음 작업>.html`을 만들고, 망가지면 "복사본과 똑같은 내용으로 되돌려 줘" | Claude Code와 같은 복사본 방법을 씁니다 | 복사본 방법이 기본입니다. 대화 기록의 **Restore Checkpoint**(에이전트가 고치기 전 상태로 파일을 되돌림)도 쓸 수 있습니다 |
| Vercel 배포 (명령 실행) | 「Vercel 배포 지시문」을 보내고 `vercel` 명령 실행을 허락합니다 | 같은 지시문을 보내고, 명령 실행 허락을 물으면 `vercel` 명령인지 보고 허락합니다 | 같은 지시문을 보내고, Agent가 명령을 실행하겠다고 하면 `vercel` 명령인지 보고 허락합니다 |
| 사용 한도 확인 | 입력창 아래 줄의 사용량 표시 | 앱의 설정이나 계정 화면에서 봅니다. 위치는 앱 버전마다 다릅니다 | Cursor 설정이나 cursor.com 계정 화면의 사용량에서 봅니다 |

**허락 방식이 다를 때.** Codex와 Cursor는 작업 폴더 안의 파일을 하나하나 묻지 않고 고칠 수 있습니다. 먼저 보고 싶으면 지시문 끝에 "무엇을 바꿀지 목록으로 먼저 보여 주고, 내가 승인하면 고쳐 줘."를 붙입니다. 어느 도구든 작업 폴더 밖 수정, 배포가 아닌 설치 명령은 거절합니다.

**Vercel 로그인은 도구와 관계없습니다.** 사전 안내 5절에서 한 Vercel 로그인은 내 컴퓨터에 남아 있으므로, 다른 도구에서 배포해도 같은 Vercel 계정으로 올라갑니다.

## 바꾸는 순서

1. 지금 고치던 파일이 있으면 복사본을 만듭니다. 예) `index.html` → `index-before-<다음 작업>.html`
2. Claude Code의 대화를 끝내고, 새 도구에서 같은 작업 폴더를 엽니다.
3. "이 폴더에 무엇이 있는지 알려 줘"로 같은 폴더가 열렸는지 확인합니다.
4. 새 도구에 지금 단계를 알려 줍니다. `@worksheet.md`와 `@index.html`을 가리켜 "먼저 읽고, 지금 사이트의 섹션 목록과 섹션마다 다 된 것 · 아직 안 된 것을 짧게 알려 줘. 파일은 아직 고치지 마."라고 보냅니다.
5. 요약이 맞으면 하던 단계의 지시문부터 이어서 보냅니다.

## 바꿔 쓸 때 주의

- **새 도구는 앞 대화를 모릅니다.** 대화를 통째로 옮기지 말고, 정리된 파일만 가리킵니다.
- **같은 파일을 두 도구로 동시에 고치지 않습니다.** 한쪽 변경이 사라질 수 있습니다. 한 번에 한 도구만 씁니다.
- **파일 이름 규칙은 같습니다.** 도구가 다른 이름(예: `main.html`, `style.css`를 따로 만들기, `-backup`, 날짜 붙이기)으로 저장하면 지시문이 정한 이름으로 바꾸게 합니다. 사이트는 `index.html` 한 파일과 `images/`가 기본입니다.
- **도구가 외부 라이브러리나 빌드 도구를 설치하려 하면 거절합니다.** "외부 라이브러리 없이 HTML · CSS · JavaScript로만 index.html 한 파일에 해 줘."라고 보냅니다.
- **한도가 풀리면 돌아와도 됩니다.** 파일은 작업 폴더에 그대로 있습니다. Claude Code로 돌아올 때도 새 대화로 시작하고 4번처럼 파일을 다시 읽힙니다.

## 막혔을 때

- **새 도구가 파일을 못 찾는다** → 작업 폴더를 한 단계 위나 아래로 연 것입니다. `personal-brand-site` 맨 위 폴더를 다시 엽니다.
- **Codex에서 권한 선택이 안 보이거나 Ask for approval이 없다** → 앱을 최신 버전으로 올리고 다시 엽니다. 그래도 없으면 지시문 끝에 "내가 승인하기 전에는 고치지 마."를 붙여 씁니다.
- **Cursor가 한 번에 여러 곳을 고쳤다** → 대화 기록에서 Restore Checkpoint로 되돌리거나 복사본으로 되돌린 뒤, 고칠 곳 하나만 말해 다시 지시합니다.
- **배포 명령이 `vercel`을 찾지 못한다** → 「[공개와 배포 가이드](../guides/publish-deploy-guide.md)」의 「다시 지시하는 말」에서 "`vercel` 명령을 찾을 수 없다고 한다" 줄의 말을 보냅니다.

Claude Code의 작업 폴더 조작은 「[작업 폴더와 비공개 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」, 사이트를 고치는 한 바퀴는 「[Claude Code 사이트 제작 가이드](../guides/claude-code-site-guide.md)」를 봅니다.
